# 夜行步城

在瀏覽器裡玩的臺北風格開放世界遊戲原型。電腦和手機都能玩，手機建議橫放。

## 怎麼玩

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD | 左下搖桿 |
| 衝刺 | 按住 Shift | 「衝刺」按鈕 |
| 跳躍／手煞車 | 空白鍵 | 「跳」按鈕 |
| 轉視角 | 拖曳滑鼠，或點一下畫面鎖定游標 | 在畫面右半邊拖曳 |
| 攻擊 | 滑鼠左鍵 | 「攻擊」按鈕 |
| 上下車 | F | 藍色按鈕 |
| 互動（商店、捷運、任務） | E | 藍色按鈕 |
| 換武器／裝填 | Tab、滾輪／R | 「武器」按鈕 |
| 手機／地圖／選單 | T／M／Esc | 左上按鈕 |

## GPS 步行模式

選單裡的「GPS 系統面板」可以切換成 GPS 步行玩法。放在 GitHub Pages 這類 HTTPS 網址上時，「改用手機 GPS」可以讀取手機的真實定位（瀏覽器會先詢問權限）。

## 檔案

- `index.html`：遊戲本體
- `three.min.js`：3D 引擎 [three.js](https://threejs.org/) r128，MIT 授權

遊戲中的店名、品牌與角色皆為虛構。
